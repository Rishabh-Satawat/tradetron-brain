# tradetron-brain

Canonical knowledge base for a Tradetron + Kite Connect agent program.

**00_CORRECTIONS_LEDGER.md is the single source of truth.** Every agent
working on this program must read it at the start of every session and
treat it as overriding its own training memory.

Contents are knowledge only: exchange parameters, Tradetron engine
behaviour, and a log of errors already made. No credentials, no account
identifiers, no position or capital data are ever committed here.
